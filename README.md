# WSO2 Identity Platform

Public issue tracker for the WSO2 Identity Platform SDKs and sample projects.

Issues for every SDK and sample repository in the [WSO2 Identity Platform](https://github.com/asgardeo) organization are filed here, so there is one place to search, report and triage. Those repositories point their **New issue** page to this repository.

## Reporting an issue

[Open an issue](https://github.com/asgardeo/asgardeo/issues/new/choose) and pick the form that fits: bug, improvement or new feature. Each form asks which package or sample the issue is about, and a workflow adds the matching label.
